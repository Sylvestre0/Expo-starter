# 🚀 expo-starter

Uma CLI simples e eficiente para gerar rapidamente projetos Expo com estrutura modular e organização profissional.

## 💡 Por que esse projeto existe?

Ao iniciar projetos com Expo, percebi que o boilerplate padrão frequentemente levava a estruturas desorganizadas e pouco escaláveis. O `expo-starter` foi criado para resolver exatamente isso:

> **Facilitar a criação de projetos com uma estrutura inicial mais limpa, modular e pronta para escalar.**

Essa CLI automatiza a criação de um projeto base com boas práticas, separação de responsabilidades e navegação já configurada — ideal para quem quer agilidade sem abrir mão da qualidade.

---

## ✨ O que essa ferramenta faz?

A `expo-starter` cria um projeto Expo com:

- Estrutura modular com separação clara de telas, fontes, imagens e roteamento
- Carregamento de fontes customizado com hook isolado (`fonts.ts`)
- Navegação entre telas já configurada via `expo-router`
- Tela inicial e tela secundária prontas para desenvolvimento
- Arquivos essenciais configurados: `_layout.tsx`, `tsconfig.json`, `.gitignore`, `declarations.d.ts`
- Instalação com correções de avisos e vulnerabilidades do npm
